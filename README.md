# Meal Planner & Ingredient Checker

A mobile-first web app for people with food allergies or diabetes, and parents of children with allergies. Built for the HCI course project (Group 6) from our Figma high-fidelity prototype.

**Live website:** https://hebadaher.github.io/meal-planner/

## What it does
- **Sign up and create a profile:** allergens with severity, or a sugar limit per serving.
- **Scan a packaged product:** clear Safe / Not safe / Uncertain results, with the reason.
- **Find recipes that fit the profile:** suggested sugar swaps.
- **Plan the week:** a weekly meal plan with a shopping list.

## Usability data
With the visitor's consent, the site records time spent, time per activity and taps. It sends them to a Google Sheet so the team can evaluate usability goals 3, 6 and 7.
